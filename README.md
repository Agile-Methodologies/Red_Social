# Red_Social-

# Descripción:
Este proyecto consiste en el desarrollo de una red social básica utilizando únicamente tecnologías web fundamentales: HTML, CSS y JavaScript. La información se almacenará localmente mediante Local Storage, sin utilizar bases de datos ni frameworks.

El objetivo es aplicar la metodología XP, trabajando de manera colaborativa en un repositorio compartido donde todos los integrantes participen en el desarrollo y roten los diferentes roles del equipo.

# Tecnologías Utilizadas
- HTML5
- CSS3
- JavaScript Vanilla
- Local Storage
- Boostrap
